# Login / Sign Up

A combined sign-in and sign-up screen. Clicking "Sign up" or "Sign in" on the side panel triggers a sliding animation that swaps between the two forms. The forms are front-end only, with no submission logic.

## Stack

- HTML5
- CSS3 (transitions, responsive layout with media queries, Poppins from Google Fonts)
- Vanilla JavaScript (toggles the sign-up mode)
- Font Awesome icons

## Running locally

No build step - open `index.html` in a browser.

## Structure

```
index.html
style.css
app.js      # switches between sign-in and sign-up
img/
```
